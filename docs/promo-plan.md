| 属性 | 内容 |

## 1. 宣传目标

1. **立规矩**：让师生干部理解——系统不是「又一个办公系统」，而是把议事规则变成可执行、不可绕过的流程。  
2. **促采用**：推动二级学院从「纸质+微信群」转向「全流程线上留痕」，形成可复制的试点样板。  
3. **强信任**：向书记、院长、班子成员讲清「AI 只辅助、不替代审签」，消除对智能能力的顾虑。  
4. **可展示**：为组织部、巡视迎检、校内信息化成果展提供统一话术、演示路径与物料。

### 阶段性目标（建议）

| 阶段 | 时间 | 目标 |
|------|------|------|
| 认知期 | 第 1–2 周 | 校领导、组织部、试点学院班子知晓定位与红线 |
| 体验期 | 第 3–6 周 | 2–3 个学院完成一次完整双会闭环演示 |
| 推广期 | 第 7–12 周 | 覆盖更多学院；形成操作手册与常见问题库 |
| 巩固期 | 持续 | 巡视材料包、监管看板成为常态工作抓手 |

## 4. 价值主张（对外可讲的「五个一」）

1. **一套制度两套会**：党委会与联席会流程隔离、名单隔离、权限隔离，前置可转、不可相互替代。  
2. **一道硬门槛**：法定人数、双人联审、材料齐备、回避、表决基数、纪要双签——不合规则阻断，不靠自觉。  
3. **一条督办链**：决议通过即生成任务，催办、逾期、重大调整回流上会，办结可问责。  
4. **一份巡视包**：校院两级台账 + 预警 + 一键导出，迎检从「翻柜子」变成「点一下」。  
5. **一位 AI 助手（可选）**：材料摘要、纪要初稿、规则问答、申报建议、审题简报——**只辅读，不代审、不代签、不代计票**。

## 5. 差异化卖点（相对「传统会务」）

| 传统做法 | 本系统 |
|----------|--------|
| Word/Excel + 微信群传材料 | 议题材料清单 + 阅件回执 + 操作审计 |
| 人数靠目测、票数靠手记 | 签到实时算法定人数；应到基数自动计票 |
| 临时动议口头带过 | 临时动议须说明材料 + 书记/院长审签 |
| 纪要「谁写谁说了算」 | 联席双签 / 党委书记签后生效 |
| 决议开完就散 | 自动督办 + 催办 + 逾期扫描 |
| 巡视前突击补材料 | 档案中心按会议全宗随时可查可导 |
| 制度靠培训记忆 | 合规引擎会中阻断 + 规则问答可查出处 |

## 7. 关键话术（可直接照读）

### 7.1 30 秒电梯稿

> 我们做的是二级学院「党委会 + 党政联席会」一体化系统，依据曲师大委字〔2021〕20 号，把法定人数、双审、回避、表决、纪要双签、督办这些规矩做成系统硬校验。开完会决议自动进督办，巡视材料可以一键导出。AI 可以帮看材料、起草纪要初稿，但审题和签署必须人来做。

### 7.2 面向书记 / 院长（2 分钟）

> 系统尊重双会各自的议事边界：党委会由书记审题、书记签纪要；联席会是书记与院长双审、双签。临时动议、紧急临机、党委会前置，都按规则留痕，不能口头带过。您在手机或电脑上处理待办即可，不会改变「谁有权谁签字」这一条。

### 7.3 面向秘书（2 分钟）

> 申报时系统按分类给出材料清单；会中有签到、表决、形成决议、结束会议的清晰步骤；散会后起草纪要、催办督办、归档都在同一条链上。以前靠群里催、表里对，现在工作台把待办收齐，少返工、少漏项。

### 7.4 关于 AI（必讲，防误解）

> AI 是「辅读助手」：摘要、初稿、规则问答、申报建议、审题简报。  
> **不做四件事**：不自动同意审题、不自动形成决议、不自动签署纪要、不自动办结督办。  
> 界面固定提示：须人工核对，以制度与原文为准。

## 8. 演示路径（宣传现场推荐）

### 8.1 十分钟版（领导参观）

1. 工作台：待办与双会流程环节一目了然  
2. 联席会议题：申报 → 材料清单 →（可选）AI 申报建议  
3. 书记 / 院长双审；展示审题简报（辅读）  
4. 开会：签到 → 法定人数达标 → 表决计票 → 形成决议 → **结束会议**  
5. 纪要双签 → 督办任务出现  
6. 校级监管：三院对比 + 预警 + 巡视导出入口  

**演示账号**：`office` → `secretary` / `dean` → `admin`（密码演示环境均为 `123456`）

### 8.2 二十五分钟版（试点学院培训）

在十分钟版基础上增加：党委会独立链路、转联席、临时动议、请假与缺席意见不计票、阅件回执、操作审计、档案中心。

## 10. 成效指标（宣传时可承诺「可衡量」，勿过度承诺）

| 指标 | 说明 | 宣传表述建议 |
|------|------|--------------|
| 双审完成时效 | 提交审题 → 双审结束 | 「审题进度可追踪」 |
| 材料缺项退回率 | 申报辅助与清单是否减少返工 | 「一次交齐材料」 |
| 散会 → 纪要生效时长 | 初稿是否提速 | 「纪要从小时级到可当日签」 |
| 督办按期办结率 | 催办与逾期扫描 | 「决议有下文」 |
| 巡视材料准备时长 | 导出替代人工汇编 | 「迎检材料一键出」 |
| AI 采纳率 | 摘要/纪要是否被采用 | 内部指标，对外慎讲绝对数 |

## 11. 风险与口径（宣传红线）

1. **不宣传「智能审批」「一键通过」**——避免制度风险与信任崩塌。  
2. **涉密议题**：强调权限隔离、下载审计；外发大模型可按学院关闭。  
3. **与纸质并行期**：宣传「系统为准、纸质可归档备份」，避免「必须立刻无纸化」引发抵触。  
4. **试点失败叙事预案**：若某院流程卡顿，口径为「规则校验生效、需补材料/补审签」，而非「系统不好用」。
