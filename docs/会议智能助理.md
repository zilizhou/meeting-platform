# 会议智能助理（Agent）方案与说明

| 属性 | 内容 |
|------|------|
| 定位 | 会议事务助理：汇报、问答、引导办理；权力行为须本人确认 |
| 当前版本 | agent-chat-v2 |
| API | `/api/agent/status`、`/api/agent/chat`、`/api/agent/confirm/:actionId` |

## 已开放能力

| 能力 | 示例问法 |
|------|----------|
| 今日简报 | 「今日简报」 |
| 待办/进展 | 「我有哪些待办？」「会议进展如何？」 |
| 议题简报 | 在议题页问「这个议题怎么样？」 |
| 会议简报 | 在会议页问「这场会怎么样？」 |
| 风险阻断解释 | 「为什么不能形成决议？」「缺什么材料？」 |
| 审题意见草稿 | 「帮我写审题意见草稿」（仅草稿，不自动提交） |
| 未读消息摘要 | 「未读消息」 |
| 督办预警 | 「督办预警」 |
| 议题搜索 | 「查找实验室设备」 |
| 议事规则问答 | 「缺席意见算不算票？」 |
| 确认卡引导 | 「帮我投赞成票」→ 仅引导，不自动投票 |

## 红线

1. 不得自动同意审题、形成决议、签署纪要、办结督办、代投票。  
2. 高风险确认卡 `executable=false`。  
3. 对话写入 `AiGeneration(kind=AGENT_CHAT)` 与审计。
